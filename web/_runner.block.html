What the in-browser run cannot do: there is no git in the sandbox, so commit metadata, churn and the hotspot-churn rules are skipped, and cloning a repository URL needs the local server or the CLI. Every other part of the analysis — dimensions, findings, evidence, recommendations — is the real thing. To keep it honest, the coverage section of the report will show churn as unassessed.

05 The fine print

What Sentinel won't pretend.

Trust comes from stating the edges. These are not hidden flaws — they are the boundaries of the claim, written where you can read them.

calibrated against 15 real repositories
The band is provisional. A coarse band — maintained, adequate, weak, unmaintained — not a letter grade. Per-dimension grades stay visible as the evidence.
Signals, not proofs. Test mapping is static evidence, not runtime coverage, and the security pass checks basic patterns rather than auditing.
It reports; it does not fix. No autofix, no pull requests, no test runner. Docs translations, examples, generated and vendor trees are out of scope.
The findings list is the primary output. Everything else supports it. Read the calibration notes ↗
